# 要件記入例: 営業ダッシュボード

Phase 1で要件が曖昧な場合の参考。

## 5W1H

**Why**: 週次の売上状況をタイムリーに把握し、目標未達のときに課題・機会を特定して対策を立てる

**What / So What**:
- 週次売上実績と目標の対比 → 未達の場合は要因分析
- 顧客属性別の売上推移 → 注力すべき顧客層の判断
- 店舗別の売上推移 → 好調・不調店舗の特定

**Who / When / Where**:
- 経営層: 隔週の経営会議で、スクリーンショットを共有
- プロジェクトメンバー: 週次のチーム会議で、モニター/ディスプレイで閲覧
- プロジェクトリーダー: 個人のノートPCで随時、課題発見と対策検討

**How**:
- 高パフォーマンスの対応良好な店舗を見つける
- 今後の開拓エリアや店舗を特定する
- 売上目標達成状況を確認し、社内報告に使用する

## データの制約
- データ集計は週次、更新頻度は週1回
- 顧客別データは月次のみ更新
- 顧客の業種ラベルは年度ごとに変わる可能性あり
- 売上取消の反映が30日遅れる。週次データは取消前の暫定値

## 必要な情報の一覧例

- 売上
  - 売上数値: 最新値、前日比、前週比、前月比
  - 時系列: 売上推移＋目標値との比較
  - 部門別: 好調・不調部門の把握＋先月比
  - 地域別: 地域差の確認＋商品別売上
- 顧客数
  - 時系列: 日次単位での変化
  - 業界別: 顧客数＋顧客あたりの売上規模
