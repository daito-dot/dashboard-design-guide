## 選定フローチャート

```
何を伝えたいか？
├── 時系列の変化を見せたい
│   ├── 連続的な変化 → 折れ線グラフ
│   ├── 累積や内訳の変化 → 面グラフ（積み上げ）
│   └── 期間ごとの比較 → 棒グラフ（縦）
├── カテゴリ間の比較をしたい
│   ├── カテゴリ数が少ない（〜7） → 棒グラフ（横）
│   ├── カテゴリ数が多い → テーブル
│   └── 比率を比較 → 100%積み上げ棒グラフ
├── 構成比を見せたい
│   ├── カテゴリ数が少ない（〜5） → ドーナツチャート
│   └── カテゴリ数が多い → 棒グラフ or テーブル
├── 単一の重要指標を強調したい
│   └── KPIカード（大きな数値＋変化率）
└── 詳細なデータを提供したい
    └── テーブル
```

## 各チャートタイプの詳細

### 折れ線グラフ（Line Chart）
**最適な用途**: 時系列の連続的な変化、トレンドの把握
**適するデータ**: 時間軸に沿った連続データ（日次、週次、月次）
**注意点**:
- 系列数は3本以内を推奨
- Y軸の範囲は意味のある範囲に設定（必ずしも0始まりでなくてよい）
- マーカー付きにするとデータポイントが明確になる

```javascript
// Chart.js設定例
{
  type: 'line',
  options: {
    scales: { y: { beginAtZero: false } },
    plugins: { tooltip: { enabled: true } },
    elements: { point: { radius: 3 } }
  }
}
```

### 棒グラフ（Bar Chart）
**最適な用途**: カテゴリ間の比較、期間ごとの量の比較
**適するデータ**: 離散的なカテゴリデータ、期間ごとの集計値
**注意点**:
- **Y軸は必ず0から始める**（これは厳守）
- カテゴリが長いテキストなら横棒グラフを使う
- 意味のある順序で並べる（大きい順、時間順など）
- 色は1〜2色に抑える（比較要素ごとに色分け）

```javascript
// 横棒グラフ例
{
  type: 'bar',
  options: {
    indexAxis: 'y',  // 横棒
    scales: { x: { beginAtZero: true } }
  }
}
```

### 面グラフ（Area Chart）
**最適な用途**: 累積値の時系列変化、内訳の推移
**適するデータ**: 積み上げ可能な時系列データ
**注意点**:
- 構成比を伝える必要がないなら折れ線グラフを使う
- 積み上げ面グラフでは下の系列が見えにくくなる
- 系列の順番に注意（変動が大きいものを上に）
- 半透明にして重なりを見えやすくする
- 100%積み上げ面グラフは構成比の時系列変化を示すのに有効
- 系列数が多い場合は棒グラフのほうが適する

### 円グラフ / ドーナツチャート（Pie / Donut Chart）
**最適な用途**: 全体に対する構成比をコンパクトに伝える
**適するデータ**: 合計100%になるカテゴリデータ。全体の総量が明らか。
**注意点**:
- カテゴリは5個以下＋「その他」が上限
- 最も大きいカテゴリを12時の位置から時計回りに配置
- ドーナツチャートを推奨（中央に数値を表示できる）
- 多くの場合、棒グラフのほうがデータを正確に伝えられる
- 全体の総量が時間変化をともなう場合は面グラフが適する

### KPIカード
**最適な用途**: 最も重要な単一指標の強調表示
**構成要素**:
- 指標名（ラベル）
- 現在値（大きなフォント）
- 変化量・変化率（前期比、前年比）
- 変化の方向（▲▼ やカラーで示す）

実装コード例は `output-templates.md` を参照。

### テーブル
**最適な用途**: 詳細データの提供、正確な数値の参照
**注意点**:
- 数値は右揃え、テキストは左揃え
- ヘッダー行は固定（スクロール時も見える）
- 行数が多い場合はソート・フィルタ機能を追加
- ゼブラストライプ（交互の行色）で可読性向上
- 重要な値はボールドまたはカラーで強調

## チャートデザインの原則

グラフ設計の原則（シンプルにする、意味のある順列、強弱、凡例の近接等）とDo's/Don'tsの詳細は `design-principles.md` を参照。

以下はチャート選定・実装時に特に注意すべきルール:

1. **棒グラフのY軸は0始まり**: 差を誇張しないため（厳守）
2. **単位やスケールが異なる指標を同一チャートに入れない**（厳守）: 二重軸もグループ化棒グラフでの混在も禁止。異なる単位の棒を同じ軸に並べると、棒の長さの比較が無意味になる。指標ごとに別のチャートに分ける
3. **良し悪しの方向が逆の指標を同一チャートに入れない**（厳守）: 「高いほど良い」指標と「低いほど良い」指標を同じチャートに入れると、見た目が意味を歪める。方向が同じ指標同士でグルーピングする
5. **切り取ったY軸範囲には注記**: 0始まりでない場合は波線や注記で明示
6. **トレンド線には根拠を**: 恣意的な近似線は入れない
7. **軸ラベルと単位を明記**: 何の数字かわからないチャートは無意味
8. **データの定義を明示**: 「売上」が税込か税抜か、など
9. **更新日時を表示**: データがいつの時点のものか常に明示
