## チャート用カラー

### プライマリカラー（メインの系列に使用）
Blue系を基本とする。1系列ならBlue 600、複数系列なら以下の順で割り当て：

```
1系列目: #3460FB (Blue 600)
2系列目: #0017C1 (Blue 900)
3系列目: #7096F8 (Blue 400)
4系列目: #000060 (Blue 1200)
5系列目: #C5D7FB (Blue 200)
```

### セカンダリカラー（強調・対比に使用）
Yellow系（注意喚起、ハイライト）：
```
Yellow 600: #FFC700
Yellow 900: #D2A400
Yellow 1200: #A58000
```

### 複数カテゴリの配色（6色以上必要な場合）
異なるカラーファミリーから600レベルを選択：
```
#3460FB (Blue 600)
#0083C1 (Light Blue 600)
#008B88 (Cyan 600)
#197A4B (Green 600)
#BD6C00 (Orange 600)
#FE3939 (Red 600)
```

## セマンティックカラー

用途に応じた意味を持つ色：

| 意味 | 色名 | Hex | 用途 |
|------|------|-----|------|
| ポジティブ / 増加 | Blue 600 | #3460FB | 数値の増加、良い傾向 |
| ネガティブ / 減少 | Red 600 | #FE3939 | 数値の減少、悪い傾向 |
| 成功 | Green 600 | #197A4B | 目標達成、正常状態 |
| エラー / 警告 | Red 900 | #CE0000 | エラー状態、要注意 |
| 注意 | Yellow 600 | #FFC700 | 注意喚起、ハイライト |

**注意**: 赤＝悪い、青＝良い は固定ではない。文脈に応じて使い分ける。ただしダッシュボード内では一貫性を保つこと。

## 使い方のルール

1. **チャートの色は1〜5色に抑える**。6色以上必要な場合は「その他」でまとめることを検討
2. **同系色のグラデーション**を使って階層を表現（例：Blue 200→400→600→900）
3. **色だけで情報を伝えない**。パターン、ラベル、形状を併用する（アクセシビリティ）
4. **コントラスト比の確保**（段階的に対応する）:
   1. 背景色とグラフ色面のコントラスト比を3:1以上にする
   2. 3:1を確保できない場合、グラフの色面領域のすぐ近くに数値を記載する（数値の色は背景色に対して4.5:1以上）
   3. 上記も困難な場合、マウスオーバーまたはキーボードフォーカス時に数値を表示する
5. **一貫性**：同じ意味には同じ色を使い続ける
6. 虹色パレット（赤→黄→緑）は避ける。色覚多様性に配慮できない
7. **色覚多様性への配慮**: カラーユニバーサルデザイン推奨の配色を参考にし、色覚特性シミュレーションで見分けにくい組み合わせがないか確認する
