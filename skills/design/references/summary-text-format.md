# ダッシュボード要約テキストフォーマット

アクセシビリティ対応として、ダッシュボードの内容をテキスト形式で要約したドキュメントのフォーマット。スクリーンリーダー利用者やダッシュボードにアクセスできない環境でも情報を取得できるようにするためのもの。

## フォーマット構成

### ① ダッシュボードタイトル
- タグ: H1
- ダッシュボードに表示されるタイトルを記載

### ② データ更新日
- ダッシュボードのデータがいつ時点のものか記載

### ③ セクションタイトル
- タグ: H2
- ダッシュボードに複数セクションがある場合に記載

### ④ セクション説明
- 画面上に表示される主要な数値を含めて説明
- すべての数値を含める必要はないが、主要な値とハイライトを記載すると明瞭度が上がる

### ⑤ データ定義の見出し
- タグ: H2
- 「データの定義について」

### ⑥ データ定義の説明
- データ定義の説明文、または詳細な定義ページへのリンク

## 記載例

```markdown
# マイナンバーカードの普及状況

2024年1月21日 時点の数値

## マイナンバーカード
マイナンバーカードの累計申請件数（有効件数）は99,247,212件です。
累計交付枚数は97,645,168件で、人口に対する申請件数率は79.1%です。
1日あたり（直近4週平均）の申請件数は9,308件です。
先週の合計は82,573件で、前週の合計の86,121件と比べて3,548件減っています。

## データの定義について
本内容におけるデータおよび数値の内訳については、デジタル庁Webサイト
「データの定義：政策データダッシュボード（ベータ版）」をご確認ください。
```

## HTMLでの実装

要約テキストはダッシュボード内に`<details>`要素で折りたたんで配置するか、別ページとして提供する。

```html
<details>
  <summary>このダッシュボードの要約テキスト</summary>
  <div class="summary-text">
    <h2>マイナンバーカード</h2>
    <p>マイナンバーカードの累計申請件数（有効件数）は...</p>
  </div>
</details>
```
