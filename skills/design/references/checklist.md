# ダッシュボード品質チェックリスト

実装完了後、以下の27項目をすべて確認する。

## 1. 利用者の体験（User Experience）

- [ ] **UX-1**: 意思決定・行動に必要な情報が提供されているか `[手動確認]` `[→ Phase 1]`
- [ ] **UX-2**: 全体像を把握するためのベースライン指標があるか `[手動確認]` `[→ Phase 1]`
- [ ] **UX-3**: 本当に必要な情報だけに絞り込まれているか（利用頻度の低い項目は除外されているか） `[手動確認]` `[→ Phase 1]`
- [ ] **UX-4**: 不要な操作を強いていないか（数クリックで目的の情報に到達できるか） `[手動確認]` `[→ Phase 2]`
- [ ] **UX-5**: 必要な情報に迷わずたどり着けるか `[手動確認]` `[→ Phase 2]`
- [ ] **UX-6**: 複数のユーザーからのフィードバックで上記を検証・改善したか `[手動確認]` `[→ Phase 4]`

## 2. 指標と表、チャートのデザイン（Metrics, Tables & Chart Design）

- [ ] **CD-1**: 見たい数字に自然と目が行くデザインになっているか `[手動確認]` `[→ Phase 3]`
- [ ] **CD-2**: チャートや表が認識しやすい順序で配置されているか `[手動確認]` `[→ Phase 3]`
- [ ] **CD-3**: チャートと凡例が近接し、対応関係が明確か `[手動確認]` `[→ Phase 3]`
- [ ] **CD-4**: 比較や時系列変化によって差がすぐわかるか `[手動確認]` `[→ Phase 3]`
- [ ] **CD-5**: チャートの色は1〜5色に収まっているか `[自動検証可]` `[→ Phase 3 Step 3]`
- [ ] **CD-6**: チャートの要素（グリッド線、罫線）は最小限か `[自動検証可]` `[→ Phase 3 Step 2]`
- [ ] **CD-7**: 不要な装飾（画像、3D、影）がないか `[自動検証可]` `[→ Phase 3 Step 2]`
- [ ] **CD-8**: タイトル・系列名が明確で紛らわしくないか `[手動確認]` `[→ Phase 3 Step 2]`
- [ ] **CD-9**: 棒グラフの原点が0になっているか `[自動検証可]` `[→ Phase 3 Step 2]`
- [ ] **CD-10**: データの更新日が記載されているか `[自動検証可]` `[→ Phase 3 Step 2]`
- [ ] **CD-11**: 実際の利用環境・デバイスで正しく表示・動作するか `[手動確認]` `[→ Phase 3]`
- [ ] **CD-12**: ダッシュボードの読み込み速度は許容範囲か `[手動確認]` `[→ Phase 3]`

## 3. データ設計（Data Design）

- [ ] **DD-1**: ユーザーの目的に合致したデータのみが選択されているか `[手動確認]` `[→ Phase 2]`
- [ ] **DD-2**: ユーザーが見たい粒度までデータを分解できるか `[手動確認]` `[→ Phase 2]`
- [ ] **DD-3**: 更新頻度の仕組みと運用プロセスがユーザーのニーズに合っているか `[手動確認]` `[→ Phase 2]`
- [ ] **DD-4**: 量だけでは判断が難しい場合、比較可能な数字（前期比、目標値、全体平均）が提供されているか `[手動確認]` `[→ Phase 2]`
- [ ] **DD-5**: データ定義の参照が可能か `[手動確認]` `[→ Phase 2]`

## 4. アクセシビリティ（Accessibility）

- [ ] **A11Y-1**: 色だけでチャートの情報を識別させていないか（パターン・ラベルを併用しているか） `[自動検証可]` `[→ Phase 3 Step 3]`
- [ ] **A11Y-2**: チャートに代替テキスト（alt情報、aria-label）が提供されているか `[自動検証可]` `[→ Phase 3 Step 3]`
- [ ] **A11Y-3**: データファイル（Excel/CSV）が公開されているか `[手動確認]` `[→ Phase 3 Step 3]`
- [ ] **A11Y-4**: ダッシュボード情報の要約テキストが公開されているか（公開向けの場合） `[手動確認]` `[→ Phase 3 Step 3]`

## 使い方

Phase 5で全項目を確認する。

- `[自動検証可]` の項目はAIが生成物を自己チェックし、結果を報告する
- `[手動確認]` の項目はユーザーに確認を促す
- 不合格項目は `[→ Phase N]` の指示に従い差し戻す
