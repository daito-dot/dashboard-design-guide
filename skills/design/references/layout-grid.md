# レイアウト・グリッドシステム

## 基本仕様

- **基準解像度**: 1920 × 1080px（16:9）
- **カラム**: 6カラムグリッド
- **マージン**: 左右・上下に適切な余白を確保
- **ガター**: カラム間の余白

## グリッドパターン

### 6カラムグリッド
```
┌──┬──┬──┬──┬──┬──┐
│ 1│ 2│ 3│ 4│ 5│ 6│
└──┴──┴──┴──┴──┴──┘
```

コンテンツ配置の基本パターン：

### パターン1: KPIカード横並び（1カラム × 6）
```
┌──┬──┬──┬──┬──┬──┐
│K1│K2│K3│K4│K5│K6│
└──┴──┴──┴──┴──┴──┘
```
用途：主要指標を一覧表示

### パターン2: 大チャート＋サイド（4:2）
```
┌────────────┬──────┐
│   メイン    │ サブ  │
│  チャート   │チャート│
│   (4col)   │(2col) │
└────────────┴──────┘
```
用途：最も重要なチャートを大きく、補助情報をサイドに

### パターン3: 2等分（3:3）
```
┌────────┬────────┐
│チャート1 │チャート2│
│ (3col)  │ (3col) │
└────────┴────────┘
```
用途：2つのチャートを同等に比較表示

### パターン4: 3等分（2:2:2）
```
┌──────┬──────┬──────┐
│ chart│ chart│ chart│
│(2col)│(2col)│(2col)│
└──────┴──────┴──────┘
```
用途：3つの同等なチャートを並列表示

### パターン5: ワイド＋テーブル（6カラム全幅）
```
┌──────────────────┐
│ テーブル or      │
│ タイムラインチャート│
│ (6col 全幅)       │
└──────────────────┘
```
用途：詳細テーブル、タイムラインチャート

## レイアウト設計の進め方

1. **骨格レイアウト**: グリッド構造とセクション配置だけを決める。データはダミー、色はモノクロ。この段階で構造の良し悪しを判断する。
2. **モックアップ**: 骨格が定まったら、チャートを配置し、最終的なイメージを具体化する。

骨格が定まらないうちに、色やフォントなどの表層を詰めない。

## レイアウト構成の推奨順序

上から下へ、以下の順序で配置するのが基本：

1. **ヘッダー**: ダッシュボードタイトル ＋ 更新日時 ＋ フィルタ（あれば）
2. **KPIカード行**: 最も重要な指標を数値カードで横並び
3. **メインチャートエリア**: 最も注目すべきチャート（大きく表示）
4. **サブチャートエリア**: 補助的なチャート群
5. **テーブルエリア**: 詳細データ（必要に応じて）
6. **フッター**: データ定義、出典、最終更新日

## 視覚的階層のルール

- **最も重要な情報を左上に配置**: ユーザーの視線は左上→右下（Z字パターン）
- **サイズで重要度を表現**: 重要なチャートほど大きく
- **余白で区切る**: セクション間に十分な余白を取り、情報グループを明確に
- **背景色で区切る**: カード背景（白）とダッシュボード背景（#F8F8FB）のコントラストで区切る
- **情報量が多い場合はページを分割する**: 概況画面（KPI＋主要トレンド）と詳細画面に分け、ナビゲーション導線を設計する

## フィルタの配置
- フィルタは画面の上部か左部に配置する
- フィルタの影響を受ける情報はその下か右に配置する
- フィルタと影響を受ける情報との関係性がわかるように配置する
