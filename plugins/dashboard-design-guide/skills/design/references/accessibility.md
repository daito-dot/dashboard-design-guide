# アクセシビリティ要件

Phase 3 Step 3で適用する。公開向けダッシュボードでは特に重要。

## 色以外の識別手段

グラフを多色にする場合、色覚多様性への配慮が必要である。色だけで情報を識別させず、以下の手段を併用する。

- **パターン（模様）**: 斜線、ドット、クロスハッチなどで系列を区別する
- **ラベル**: データ系列名や数値をグラフ上に直接配置する
- **形状**: 折れ線グラフのマーカーに丸・四角・三角など異なる形状を使う

カラーユニバーサルデザイン推奨の配色を採用し、色覚特性シミュレーションやチェッカーで見分けにくい色の組み合わせがないか検証する。虹色パレット（赤→黄→緑）は色覚多様性に配慮できないため避ける。

## コントラスト比

背景色とグラフ色面のコントラスト比は、以下の3段階で対応する（ガイドブック4.3準拠）。

### 第1段階: 3:1以上のコントラスト比を確保

背景色に対して、グラフの色面を3:1以上のコントラスト比で配色する。例えばBlueカラーパレットをキーカラーにした場合、Blue-500（#4979F5）以上の濃さが必要。

### 第2段階: 色面の近くに数値を記載

3:1のコントラスト比を満たせない場合は、グラフの色面領域のすぐ近くに数値を記載する。数値テキストの色は背景色に対して**4.5:1以上**のコントラスト比を確保すること。

### 第3段階: マウスオーバーまたはフォーカス時に数値を表示

第2段階も実現できない場合は、色面領域をマウスオーバーまたはキーボードフォーカスした際に数値を表示する。

## 代替テキスト

グラフやチャートには代替テキスト（`aria-label`）を付与し、スクリーンリーダーでダッシュボードの情報を取得できるようにする。

### 代替テキストの書き方

1. **チャートの種類**と**タイトル**を冒頭に記述する
2. **主要な数値**や**傾向**を簡潔に伝える
3. 詳細データはデータテーブルに委ねる

```html
<!-- 棒グラフの例 -->
<div role="img" aria-label="棒グラフ: 月別申請件数。2024年1月は9,308件で最多、12月は5,200件で最少。全体として増加傾向。">
  <!-- チャート本体 -->
</div>

<!-- 折れ線グラフの例 -->
<div role="img" aria-label="折れ線グラフ: 累計交付枚数の推移。2023年1月の7,000万枚から2024年1月の9,764万枚へ約39%増加。">
  <!-- チャート本体 -->
</div>

<!-- 円グラフの例 -->
<div role="img" aria-label="円グラフ: カテゴリ別構成比。Aが45%、Bが30%、Cが15%、その他が10%。">
  <!-- チャート本体 -->
</div>
```

## キーボードナビゲーション

すべてのインタラクティブ要素をキーボードで操作可能にする。

- **Tab**: フォーカスの移動（論理的な順序で）
- **Enter / Space**: ボタンやリンクの実行
- **矢印キー**: フィルタ選択肢の切り替え、チャートのデータポイント間移動
- フォーカスインジケータを視覚的に明確にする（ブラウザデフォルトの `outline` を削除しない）
- ツールチップやポップアップはキーボードフォーカスでも表示する（マウスオーバー専用にしない）

## データテーブルの併設

ダッシュボードを見られない人やデータを解析したい人のために、チャートの元データをHTMLテーブルとして併設する。`<details>` / `<summary>` 要素で折りたたみ、画面を圧迫しないようにする。

```html
<figure>
  <div role="img" aria-label="棒グラフ: 月別申請件数（2024年）">
    <!-- チャート本体 -->
  </div>
  <details>
    <summary>データテーブルを表示</summary>
    <table>
      <caption>月別申請件数（2024年）</caption>
      <thead>
        <tr><th>月</th><th>申請件数</th></tr>
      </thead>
      <tbody>
        <tr><td>1月</td><td>9,308</td></tr>
        <tr><td>2月</td><td>8,500</td></tr>
        <!-- ... -->
      </tbody>
    </table>
  </details>
</figure>
```

## 要約テキスト

公開向けダッシュボードでは、ダッシュボードの内容をテキスト形式で要約した文書を提供する。スクリーンリーダー利用者やダッシュボードにアクセスできない環境でも情報を取得できるようにするためのもの。

フォーマットの詳細は [要約テキストフォーマット](summary-text-format.md) を参照。

## データファイルの公開

データをファイル形式（Excel / CSV）で公開し、二次利用を可能にする。

- **CSV**: 機械可読性が高く、分析ツールで直接利用可能
- **Excel**: 非技術者にも扱いやすい
- ファイルのデータ形式（エンコーディング、区切り文字）と構造（カラム定義、単位）を明示する
- データ更新時にファイルも同期して更新する
